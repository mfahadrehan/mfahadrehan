## 🚀 Featured Project

### 🧬 [ImmunoAI](https://github.com/mfahadrehan/IMMUNOAI) — Hybrid AI Diagnostic System
> Multimodal Clinical Decision Support System for rare autoimmune diseases

A 3-stage transfer-learning vision pipeline (ResNet50) with Grad-CAM heatmaps and SHAP explainability, fused with a stacking ensemble (Random Forest + XGBoost + LightGBM + Logistic Regression meta-learner) over tabular clinical data — plus a RAG-based chatbot (Llama-3-70b + Pinecone) on a Django REST + React 18 + Tailwind stack.

> `97.92%` MRI vision accuracy &nbsp;·&nbsp; `93%` fusion model accuracy &nbsp;·&nbsp; `81.56%` tabular accuracy
